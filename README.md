# SEP11 Freedom Project
by **Abdel Ebed**

## Context
I am a student at [HSTAT](https://www.hstat.org/) in the [Software Engineering Program](https://hstatsep.github.io/).
  The "Freedom Project" for SEP11 is a year-long project using code to create a product, with vast possibilities, from a game, to a quiz app, to a website, most things are possible.

For my project, I chose the topic of **Waking up**. This project is a Smart Alarm Clock that attempts to make someone's, being my, morning, less chaotic, and compact into one small device that will not distract.

I used ESP32D, LCD screen, and Arduino C++ to create it.
